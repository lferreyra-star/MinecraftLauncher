Preguntar en GitHub
¿Es un launcher oficial de Minecraft?

No. XD Launcher es un proyecto no oficial y no está afiliado a Mojang Studios ni a Microsoft. Usa siempre juegos y servicios oficiales.

¿Necesito instalar .NET por separado?

No. El instalador incluye el runtime necesario: funciona en Windows 10/11 de 64 bits sin instalar .NET aparte.

¿Mobile Connect copia el juego o toca mis mundos?

No. Transmite la pantalla del Minecraft Bedrock que ya tienes en el móvil mediante ADB y scrcpy. No modifica mundos, skins, addons ni tu cuenta.

¿Puedo usar mods y Fabric en Java Edition?

Sí. Puedes instalar Fabric desde Fabric Meta y gestionar mods y modpacks compatibles desde el centro de mods, en workspaces separados.

¿Cómo inicio sesión?

Puedes usar Google o correo y contraseña en la web, y continuar en el launcher de escritorio. También puedes jugar con perfil local o cuenta Microsoft en el launcher.

¿Dónde se descarga la última versión?

Siempre en GitHub Releases. El instalador se llama MinecraftLauncher_Setup.exe.
